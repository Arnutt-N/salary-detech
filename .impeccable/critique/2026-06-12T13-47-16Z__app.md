## Overall Impression

Salary Detech now feels like a clerk's working console, not a prototype. Since the prior critique (26/40), loading skeletons, mobile nav, touch targets, empty states, and Thai batch labels materially improved trust and usability. The biggest remaining gap is copy consistency (English "stale" leaking into Thai UI) and explaining freshness flags without domain expertise.

## What's Working

1. **Workflow-first IA** — Sticky nav links dashboard → stale report → orders/batches; KPI cards and stale table rows deep-link to employees and orders.
2. **Supportive empty states** — Dashed-border `EmptyState` with verb+object CTAs; `GettingStartedPanel` guides first import on empty DB.
3. **Accessible table sorting** — `DataTable` sort headers are focusable buttons with `aria-sort`, fixing the prior P1 keyboard gap.

## Priority Issues

**[P1] Residual English "stale" in user-facing copy**
- **Why:** PRODUCT.md promises Thai-first; strings like "เปิดรายงาน stale", "ไม่พบคำสั่ง stale", and GettingStarted step 3 action break trust for HR officers.
- **Fix:** Replace with "ต้องแก้ไข" or "รายงานคำสั่งที่ต้องแก้ไข" everywhere users read it (keep `stale` in code/URLs only).
- **Suggested command:** `/impeccable clarify`

**[P1] Freshness badges communicate status by color only**
- **Why:** On order detail, `FreshnessBadge` shows dimension label ("เงินเดือน") plus emoji/color but not `getFreshnessFlagLabel()` text; fails color-only recognition for Sam and low-contrast displays.
- **Fix:** Append status label ("ต้องแก้ไข", "ล่าสุด", "แก้ไขแล้ว") or add visible text beside icon; ensure ≥4.5:1 on amber/red/green surfaces.
- **Suggested command:** `/impeccable audit`

**[P2] Dashboard stale work has four parallel entry points**
- **Why:** Nav item, red KPI card, quick-action button, and on-page `#stale` section compete for attention when `staleCount > 0`; increases extraneous cognitive load for Jordan.
- **Fix:** Hide quick-action red button when stale KPI is visible; demote or collapse duplicate section header actions.
- **Suggested command:** `/impeccable distill`

**[P2] Batch detail person column is plain text**
- **Why:** Batch order table shows names without `/employees/[id]` links while dashboard stale table links names; inconsistent affordance on a high-stakes approve flow.
- **Fix:** Link person names when `person.id` is available, matching stale report patterns.
- **Suggested command:** `/impeccable polish`

**[P2] No contextual help on freshness dimensions or batch approve**
- **Why:** Batch stats (กระทบ, ติดขัด, กระทบต่อเนื่อง) and five freshness flags assume domain knowledge; heuristic #10 stays weak after first-run panel.
- **Fix:** Add compact inline help (tooltip or `<details>`) on batch stats and order freshness section, one sentence per term in Thai.
- **Suggested command:** `/impeccable onboard`

## Persona Red Flags

**Sam (Accessibility):** Emoji prefixes in nav link text ("📊 แผงควบคุม") add screen reader noise; freshness status relies on color + emoji without explicit status words on order detail.

**Casey (Mobile):** Primary actions now meet 44px via `btn-touch`; wide tables scroll horizontally without sticky first column, so employee name disappears while scrolling warnings on small phones.
