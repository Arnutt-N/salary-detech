## Anti-Patterns Verdict

**LLM assessment:** Does not read as SaaS marketing AI slop. No gradient heroes, side-stripe cards, or eyebrow scaffolding. Reads as a credible internal HR tool with shadcn-adjacent zinc palette. Residual tells: emoji prefix on every nav item and page title, six-up KPI card grid, gray-50 page wash (acceptable for product register but generic).

- `gray-on-color` on `StaleTable.tsx:84` — **likely false positive**; active stale badge uses `text-red-700` on `bg-red-50`; superseded uses zinc-on-zinc.

## Overall Impression

Salary Detech already feels like a clerk's desk, not a landing page. The biggest gap is language consistency and accessibility on data tables, not visual novelty.

## What's Working

1. **Workflow-first IA** — Nav links dashboard → stale report → orders/batches with KPI cards deep-linking to the same destinations.
2. **Semantic color discipline** — Blue for actions, red for stale, green for export; alert KPI cards switch surface when count > 0.
3. **Thai date honesty** — Business dates use `toThaiDate` (พ.ศ.) on order/stale surfaces; supportive empty states ("ไม่มีคำสั่งที่ต้องแก้ไข").

## Priority Issues

**[P1] Mixed EN/TH labels break trust for HR officers**
- **Why:** PRODUCT.md promises Thai-first; labels like "Active", "Audit", "Blocker", "Cascade", "Effective", and empty-state "stale" force translation.
- **Fix:** Route all status/type labels through `lib/order-types.ts`; Thai batch status labels where E2E allows.
- **Suggested command:** `/impeccable clarify`

**[P1] Sortable table headers are click-only**
- **Why:** `DataTable` uses `onClick` on `<th>` without `tabIndex`, keyboard handler, or `aria-sort` — blocks keyboard-only users (Sam).
- **Fix:** Use `<button>` inside header cells or add keyboard + ARIA sort pattern.
- **Suggested command:** `/impeccable audit`

**[P1] Dashboard stale table: employee names not linked**
- **Why:** Recent activity links employee names; stale section shows plain text — inconsistent affordance for the primary fix workflow.
- **Fix:** Wrap stale employee names in `/employees/[id]` links like recent activity.
- **Suggested command:** `/impeccable polish`

**[P2] Dashboard cognitive duplication**
- **Why:** Four paths to stale work (nav, KPI, quick action, on-page section) plus six KPI tiles competes for attention.
- **Fix:** Collapse quick actions when KPI row exists; demote redundant red button if stale KPI is visible.
- **Suggested command:** `/impeccable distill`

**[P2] No loading skeletons on data-heavy routes**
- **Why:** Server components fetch multiple queries; users see blank wait without progress (heuristic #1 gap).
- **Fix:** Add `loading.tsx` per route with table/KPI skeletons matching DESIGN.md flat surfaces.
- **Suggested command:** `/impeccable onboard`
